PROJECTS

My Projects

01

IoT-Based Industrial Hygiene Early Warning System with Hazard Condition Prediction Using Artificial Neural Network–Multi Layer Perceptron (ANN-MLP)

This Skripsi project developed an IoT-based Industrial Hygiene Early Warning System to monitor room temperature and noise levels in real time. The system uses sensors with Modbus RTU communication and a Raspberry Pi as an edge computing device to process and transmit the collected data. An Artificial Neural Network–Multi Layer Perceptron (ANN-MLP) model is implemented to predict room conditions up to one hour ahead, enabling the system to provide early warnings of potential hazardous conditions.

Raspberry Pi Python IoT Modbus RTU Supabase Grafana ANN-MLP
02

Real-Time AHU Temperature and Humidity Monitoring System with Modbus TCP/IP and WhatsApp Alerts

This project was developed to simplify and centralize the monitoring of temperature and humidity across nine AHU rooms into a monitoring dashboard at PT Oneject Indonesia. The rooms included are Assy BCT P2, Assy Needle P1, Assy Syringe P1, Assy Syringe P2, Blood Bag AHU 1, Blood Bag AHU 2, Blood Bag AHU 3, Injection P1, and Injection P2. The system utilizes Autonics THD sensors and transmitters to acquire environmental data and employs the Modbus TCP/IP protocol to ensure reliable communication for real-time monitoring.

Modbus TCP/IP Node-RED PostgreSQL WhatsApp API IoT Real-Time Monitoring Grafana
03

Design HMI display for counter on the E-Beam conveyor with Mitsubishi PLC.

This project was developed to make it easier for operators to monitor boxes or item passing the sensor on the conveyor. Its features include a display showing the number of boxes and batches that have passed the sensor, as well as a reset button.

PLC Mitsubitshi HMI Haiwel Industrial Automation

Monitoring System Injection Molding Machine

This project involves developing a monitoring system for injection molding machines located in the injection room. The monitoring data is displayed on a TV in the molding room. The system features machine status, a counter, set values, alarms, alarm history, and a predictive maintenance schedule.
